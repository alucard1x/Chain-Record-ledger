How it works

Four steps keep every record honest.

  1. {{ icon('hash') }}
    Every record is hashedSHA-256 fingerprints roll no, name, subject, marks, semester, time and the previous hash.
  2. {{ icon('link') }}
    Blocks are chainedEach block stores the previous block's hash. Change one mark and the chain breaks there.
  3. {{ icon('anchor') }}
    The chain is anchoredThe latest hash and count live outside the database, so a rebuilt chain is caught.
  4. {{ icon('qr') }}
    Anyone can checkEvery marksheet's QR code opens its live verification page. No login needed.
